# Study Planner

A small task tracker for students to plan their study work. Add tasks, set priorities and due dates, and watch your progress grow.

## About This Project

I built this mini project to practise intermediate HTML, CSS and JavaScript. It runs entirely in the browser, with no install and no server.

## Technologies Used

- HTML5 – For the page structure and form.
- CSS3 – For styling, layout and the light and dark themes.
- JavaScript – For all the app logic, searching and saving.

## Features

- Add tasks with a subject (Maths, Physics, Chemistry, Coding or Other), a priority and a due date.
- Tick tasks off, edit a title in place, or delete a task.
- Search tasks, filter by All, Active or Done, and sort by due date, priority or newest.
- Progress bar showing how much is done.
- Overdue tasks are highlighted.
- "Clear completed" button (click twice to confirm).
- Tasks are saved in your browser, so they are still there next time.
- Dark and light mode toggle.
- Responsive design for desktop and mobile.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Learning Outcomes

Through this project, I practised:

- Creating elements with `createElement` and `textContent`.
- Event delegation, with one listener handling every button in the list.
- Array methods such as `filter`, `sort` and `forEach`.
- Saving data with `localStorage` and JSON.
- Responsive layouts with CSS grid and flexbox.
